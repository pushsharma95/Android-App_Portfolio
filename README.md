# Android-App_Portfolio
A Sample e-commerce application built using Kotlin, Jetpack Compose, Clean Architecture with DI (Dagger Hilt), featuring product discovery , category browsing , wishlist management and shopping cart functionality,

Technology Stack :
Kotlin.
Jetpack Compose.
MVVM Architecture.
Clean Architecture.
Room DB
Kotlin Corotines
Flow.


Key Feature :
Dynamic product categories & Product Listing.
Product Details & brand-based filtering.
Wishlist functionality locally managed.
Product Quantity Management
